# Botium Toys – Internal Security Audit

## Project Overview

This project presents a simulated internal security audit for Botium Toys, a fictional company used in a cybersecurity case study.

The purpose of the audit was to assess the company's existing security controls, identify security and compliance gaps, evaluate potential risks, and provide recommendations for improving its overall security posture.

## Audit Scope

The audit covered the organization's overall security program, including:

- Employee devices and equipment
- Internal network and systems
- On-premises infrastructure
- Accounting and database systems
- E-commerce and inventory systems
- Customer and employee data
- Cardholder data
- Data storage and retention
- Legacy systems
- Physical security controls

## Risk Assessment

Botium Toys was assessed with an overall risk score of 8/10, indicating a relatively high level of risk.

The assessment identified several weaknesses in access control, data protection, security monitoring, backup and recovery, password management, and compliance practices.

## Key Findings

The audit identified the following key security gaps:

- Least privilege was not implemented.
- Separation of duties was not implemented.
- Sensitive data was accessible to all employees.
- Cardholder data was not encrypted.
- No intrusion detection system (IDS) was implemented.
- Critical data was not regularly backed up.
- No disaster recovery plan was in place.
- Password requirements did not meet current security standards.
- No centralized password management system was implemented.
- Data classification and inventory practices needed improvement.
- Legacy system maintenance procedures were not sufficiently defined.

## Recommendations

Based on the assessment, Botium Toys should prioritize strengthening access controls by implementing least privilege and separation of duties.

Sensitive and cardholder data should be encrypted, while password requirements and centralized password management should be improved.

The company should also implement regular backups, a disaster recovery plan, and an intrusion detection system.

Additionally, Botium Toys should maintain an accurate asset inventory, improve data classification, establish regular legacy system maintenance procedures, and conduct periodic security and compliance reviews.
